Scope and change rules

All indications and phases, including healthy-volunteer studies. Multinational trials qualify when a non-US country is explicitly listed. Unknown geography and US-only studies are excluded from discovery. Baseline items describe existing records, not newly registered trials. Item dates are observation dates; registry dates retain their labels. Updates to title, indication, phase, recruitment, enrollment, geography, study dates, outcomes, eligibility, intervention or results create items. Registry refresh dates and page formatting alone do not. Failures preserve the last good data and are shown above. Cross-registry matches require an explicit shared ID or exact normalized protocol ID plus asset; titles alone are never used. Conflicting registry values remain attributed. A newly linked source may generate an item when it adds material information.
